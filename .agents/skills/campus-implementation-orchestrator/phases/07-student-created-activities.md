# Phase 7 — Student-Created Activities

## Objective
Authenticated students can create solo activities using the existing Luma event creation UI.

## Examples
DSA practice, study session, project discussion, football, photography walk, networking, gaming.

## Required
- event_type = solo
- source = student
- organizer_user_id = authenticated user
- capacity support
- normal event lifecycle
- server-side ownership enforcement

## Acceptance criteria
- A student can create an activity.
- Another user can discover it.
- The organizer cannot be spoofed by client input.
- Existing creation UI is reused.
